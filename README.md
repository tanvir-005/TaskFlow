# TaskFlow

TaskFlow is an AI-agent-powered task manager that lets users create,
search, update, complete, and delete tasks through natural-language
instructions.

## Project Status

Development is in progress.

## Technology Stack

- Backend: Python, FastAPI, Pydantic
- Database: SQLite
- Semantic Search: ChromaDB
- AI Agent: Google Gemini
- Frontend: React, TypeScript, Vite, Tailwind CSS, shadcn/ui
